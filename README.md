# UADron → Prom.ua: автоматичний XML-фід

## Запуск із нуля (GitHub Pages + GitHub Actions)

1. Створіть **публічний** репозиторій GitHub, наприклад `prom-autofeed`.
2. Завантажте в корінь репозиторію `build_prom_feed.py` та папку `.github/workflows/` із цього архіву. Переконайтеся, що прихована папка `.github` не загубилася.
3. У репозиторії: **Settings → Secrets and variables → Actions → New repository secret**. Назва: `SUPPLIER_FEED_URL`. Значення: повне оригінальне URL-посилання постачальника. **Не додавайте URL у публічний код**: параметр hash_tag може давати доступ до фіду.
4. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. **Actions → Update Prom feed → Run workflow**. Дочекайтеся зеленого статусу та відкрийте адресу GitHub Pages.
6. URL для Prom: `https://ВАШ-ЛОГІН.github.io/prom-autofeed/products.xml` (замініть логін та назву репозиторію). Вставте його в імпорт Prom та встановіть періодичність оновлення наявності **4 години**, якщо цей інтервал доступний у вашому кабінеті.
7. Автоматичний запуск на GitHub відбувається кожні 4 години (за UTC); запуск за розкладом може затримуватися, тому це **не гарантія** точної синхронізації кожні 4 години. Якщо потрібна максимально свіжа наявність, потрібна інша архітектура.

## Правила

Націнки: до 100: +100%; 250: +80%; 500: +60%; 750: +50%; 1000: +37%; 1500: +32%; 2000: +29%; 4000: +25%; 6000: +20%; 10000: +18%; понад 10000: **тимчасово +15%**. Ціни округлюються вгору до цілої гривні. Відредагуйте `OVER_10000_MARKUP` у workflow, якщо потрібно.

Вивантаження зберігає `offer id`, `vendorCode`, `available`, `quantity_in_stock`, фотографії, категорії та інші вихідні поля. Назви частково очищуються, ключові слова генеруються евристично, а описи структуровано доповнюються. **Це не гарантія 100% SEO-унікальності або коректності всіх характеристик.**

## Обмеження

- Потрібно окремо перевірити, чи Prom коректно імпортує поля `keywords`/`keywords_ua` та HTML в `description`.
- Якщо постачальник тимчасово недоступний, workflow завершиться помилкою, а попередній опублікований фід залишиться без змін. Налаштуйте сповіщення GitHub Actions про помилки.
- GitHub Pages є публічним: кінцеві ціни та дані фіду будуть доступні будь-кому за URL.
- Якщо репозиторій неактивний тривалий час, GitHub може автоматично вимкнути заплановані workflow; періодично перевіряйте Actions.
- Перед масовим імпортом протестуйте 5–10 товарів, відповідність ID, оновлення цін і залишків та поведінку відсутніх товарів.
